\# 🍱 Food Waste Management System



A web-based \*\*Food Waste Management System\*\* developed using \*\*Java Servlets, JSP, MySQL, HTML, CSS, and JavaScript\*\*. The project aims to help collect surplus food from donors and make it easier to manage and distribute food to people in need.



The system provides separate functionality for \*\*users/donors\*\* and \*\*administrators\*\*, including user registration, login, food donation, donation management, feedback management, and an administrative dashboard.



\---



\## 📌 Project Overview



Food waste is a major social and environmental concern. Large quantities of excess food can be generated by restaurants, hotels, marriage halls, events, and households.



This project provides a web-based platform where donors can submit information about available food. Administrators can then view and manage donation information through an admin dashboard.



\### Main objectives



\* Reduce food wastage

\* Encourage people and organizations to donate surplus food

\* Connect food donors with the food-management process

\* Maintain donation information in a database

\* Provide administrators with a centralized dashboard

\* Make food donation management easier

\## 🔄 How the System Works



\### 1. User Registration



A new user provides information such as:



\* Name

\* Email

\* Password

\* Phone number



The registration servlet generates a random salt and stores a hashed password in the database.



```text

User Registration

&#x20;      ↓

Generate Salt

&#x20;      ↓

Hash Password

&#x20;      ↓

Store User Information

&#x20;      ↓

MySQL Database

```



\### 2. User Login



The user enters their email and password.



The application:



1\. Searches for the user by email.

2\. Retrieves the stored password hash and salt.

3\. Hashes the entered password with the stored salt.

4\. Compares the generated hash with the stored hash.

5\. Creates a session after successful authentication.



\---



\### 3. Food Donation



After accessing the donation page, the donor can provide information about the food.



Example:



```text

Food Name

Meal Type

Food Category

Quantity

Phone Number

District

Address

Donor Name

```



The information is submitted to the server and stored in the `food\_donations` table.



\---



\### 4. Admin Dashboard



The administrator can access a protected dashboard.



The dashboard displays information such as:



```text

Total Users

Total Feedbacks

Total Donations

Recent / Unassigned Donations

```



The administrator can also filter donation information according to location/district.

\## 🔒 Security



The application includes several security-related mechanisms:



\* Password hashing

\* Random password salt generation using `SecureRandom`

\* `PreparedStatement` for database queries

\* HTTP sessions for authentication

\* Cookies for remember-me functionality

\* Admin session protection



\### ⚠️ Important Configuration Note



Database credentials should \*\*not be hard-coded in source code\*\* before publishing this project publicly.



Use environment variables or an external configuration file instead.



For example:



```text

DB\_URL=jdbc:mysql://localhost:3306/food

DB\_USER=your\_database\_user

DB\_PASSWORD=your\_database\_password

```



\*\*Never commit real database passwords, API keys, tokens, or other secrets to GitHub.\*\*

\## ⚙️ Installation \& Setup



\### Step 1 — Clone the Repository



```bash

git clone https://github.com/sayan237/-Food-Waste-Management-System.git

```



Then enter the project directory:



```bash

cd -Food-Waste-Management-System

```



\---



\### Step 2 — Create the Database



Open MySQL and create the database:



```sql

CREATE DATABASE food;

```



Create the required tables according to the SQL schema used by the application.



\---



\### Step 3 — Configure Database Connection



Update the application's database configuration with your local MySQL settings.



Typical configuration:



```text

Database: food

Host: localhost

Port: 3306

Username: your MySQL username

Password: your MySQL password

```



Do not upload the real password to GitHub.



\---



\### Step 4 — Configure Apache Tomcat



Add \*\*Apache Tomcat 10.1\*\* to Eclipse.



Then:



1\. Import the project into Eclipse.

2\. Configure the project as a Dynamic Web Project.

3\. Add Tomcat 10.1 as the server runtime.

4\. Make sure the MySQL Connector/J dependency is available.

5\. Start the Tomcat server.



\---



\### Step 5 — Run the Application



Open the application through your local Tomcat server.



The default entry point is:



```text

index.jsp

```
